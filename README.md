# SinusoidalRobot-RL-Hybrid-Stanley-PPO-Obstacle-Avoidance
Autonomous robot navigates a 10m sinusoidal path avoiding 3 static obstacles using a Hybrid Stanley Controller + PPO (Reinforcement Learning). Trained 12M steps with RPLidar A1 simulation (16-ray, 6m range). Features Top-5 episode recorder &amp; interactive showcase. Built with Stable-Baselines3 + Gymnasium.
